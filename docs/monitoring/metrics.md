All metrics available for scraping are exposed on the `/metrics` endpoint.
The metrics are in the Prometheus exposition format.

To access the metrics:

```sh
curl http://localhost:9115/metrics
```

## Supported Metrics

> Probe-specific metrics are only present in the response of the `/probe` endpoint, not on `/metrics`.
> The **Prober** column shows which probe type(s) expose the metric: `all` means every prober, `-` means it is a global metric.
